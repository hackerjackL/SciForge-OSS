# 125 Scientific Problems — Demo Index (SciForge-OSS)

> 125 个科学问题「AI for Scientist Anything」Demo 索引。
> 每个问题包含：ID、领域分类、问题描述、已知背景、所需工具/方法。
>
> **注意**: 125 题是 Demo 展示，不是完整题库。框架支持任意数量、任意领域的问题。

---

## 使用说明

本索引文件是 SciForge-open 的入口参考。当 AI Scientist 接收到一个问题时，先在此索引中查找对应条目，获取问题的完整上下文，然后启动 `/125-problems-pipeline` 执行完整的研究闭环。

| 代码 | 领域 | 说明 |
|------|------|------|
| PHY | 物理学 | 量子力学、天体物理、凝聚态、粒子物理 |
| CS | 计算机科学 | AI、ML、算法、计算理论、信息科学 |
| BIO | 生命科学 | 分子生物学、基因学、神经科学、生态学 |
| CHE | 化学 | 理论化学、材料化学、催化 |
| MAT | 数学 | 纯数学、应用数学、统计 |
| EAR | 地球科学 | 气候、地质、海洋、大气 |
| ENG | 工程 | 机器人、能源、纳米技术 |

| SOC | 社会科学 | 复杂系统、网络科学、行为科学 |
| GEN | 交叉/通用 | 跨学科、方法论、未分类 |
